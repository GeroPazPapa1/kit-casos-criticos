Step 1 — Replace Dashboard/vite.config.ts entirely with:
```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import path from 'path'

export default defineConfig({
  plugins: [react()],
  base: './',
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```
CRITICAL: `base: './'` (with trailing slash, dot-slash form) is mandatory. The scaffold
default is implicit `base: '/'` which breaks Vercel relative asset resolution. Replace the
entire file — do not merge with the scaffold output.

Step 2 — Replace Dashboard/index.html entirely with:
```html
<!doctype html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Operativo Frío · Entregas</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```
Do NOT add a `<link rel="stylesheet">` for leaflet CSS here — it will be imported in
main.tsx. Do NOT add a favicon link (D-10: no logo in v1). Set `lang="es"` and the
exact title shown above.

Step 3 — Create the destination directory and copy Comunas.json:
